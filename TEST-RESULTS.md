# Проверки v0.3

- `npm run build`: TypeScript и production-сборка проходят. Есть предупреждение о размере JS-бандла >500 KB, не ошибка сборки.
- `tests/rules.mjs`: формулы характеристик, урона, HP, каталог рецептов — PASS.
- `tests/campaign-rules.mjs`: 4 региональных замка, условия Бездны, 6 навыков и связность 5 планировок — PASS.
- `tests/network-v03.mjs`: 4 соединения + отказ пятому, один владелец тайника при конкурирующих запросах, только хозяин отправляет финал, закрытие комнаты при выходе хозяина — PASS.
- `tests/guest-world.mjs`: гость видит печати хозяина; в локальный слот пишет свой мир и личные характеристики; после выхода хозяина восстанавливает свой мир — PASS.
- `tests/campaign-browser.mjs`: загрузка ассетов, карта/замки, изучение Покрова, инвентарь, победы над 4 хранителями, улучшения хаба, переходы этажей, последний босс и сохранение каждого финала — PASS, без JS-ошибок/404 ассетов.
- `php -l backend/api.php`: синтаксис — PASS.
- `tests/php-api.mjs`: регистрация/вход/выход, чтение личного слота, изоляция владельца, конфликт ревизий, CSRF и запрет анонимной записи — PASS на PDO SQLite.

Браузерные тесты переходов/финалов используют подготовленные сохранения с повышенными характеристиками и отмеченными убитыми врагами. Это проверка отдельных границ логики, **не подтверждение прохождения всей кампании обычным персонажем**. Не тестировались production MySQL/OpenServer, реальные внешние сети с 4 игровыми клиентами, длительная нагрузка, все браузеры и полный боевой баланс. Нельзя считать эти проверки релизной приёмкой большого ТЗ.
