# Как обновить существующий Render

Исходная версия репозитория: 4f209ed1c0177081a409c5d1b0f623d888082fa9. Обновление пока находится только в переданном архиве.

## Через сайт GitHub

1. Распакуйте архив forest-ash-v0.2.zip.
2. Откройте репозиторий K1ZNA1VER017/forest, ветку main.
3. Add file → Upload files. Перетащите **содержимое** папки forest-ash-v0.2 (не саму внешнюю папку) в загрузку, сохранив структуру src/, public/, scripts/, tests/. Не добавляйте node_modules или dist.
4. Проверьте, что package.json лежит в корне и содержит version 0.2.0. В public/assets должны появиться PNG; в src — rpg.ts и v02.css.
5. Commit changes. На публичном репозитории проверьте права на ассеты перед отправкой.
6. При включённом Auto Deploy Render начнёт сборку сам. Иначе откройте сервис forest-ash → Manual Deploy → Deploy latest commit.
7. Дождитесь успешного деплоя, откройте прежний публичный адрес и обновите страницу Ctrl+F5. Адрес сервиса менять не нужно.

## Если используете Git локально

Перенесите файлы из архива в рабочую копию репозитория, затем:

```
git add .
git commit -m "Add v0.2 assets, equipment, attributes, dash and herbalist quest"
git push origin main
```

Альтернатива: приложенный `forest-v0.2.patch` применяется из корня чистой рабочей копии исходного коммита командой `git apply --index forest-v0.2.patch`. Не нужно одновременно копировать файлы из архива и применять патч.

## После обновления

- Выберите облик, проверьте вещи (I) и характеристики (C).
- Рывок — пробел; новая цель — поручение травницы.
- Старое сохранение импортируется в новый слот, исходный v1 остаётся для отката.
- При перезапуске Render текущие сетевые комнаты исчезают. Создайте комнату заново.

Новые права доступа к серверу, база данных и переменные окружения не требуются. Build/start команды и файл render.yaml сохранены.
