# Лесной пепел · v0.2

Изометрическая браузерная RPG: Three.js + TypeScript, Node.js/WebSocket. Обновление создано поверх публичного репозитория `K1ZNA1VER017/forest`, исходный HEAD `4f209ed1c0177081a409c5d1b0f623d888082fa9`.

## Запуск

Node.js 22 LTS рекомендуется (поддерживается 20.19+).

```
npm ci
npm run dev
```

Открыть `http://localhost:5173`. `npm run build` — проверка типов и сборка. Для production: сначала сборка, затем `NODE_ENV=production npm start`; на Windows задайте переменную окружения средствами вашей оболочки или используйте Render с `render.yaml`. Сервер слушает `process.env.PORT`.

## Новое в 0.2

- Вырезанные PNG из присланных листов: пять обликов героя, статичные персонажи врагов и травницы, портреты, предметы и сердца HUD.
- Новый сине-зелёный интерфейс с золотыми рамками, выбором облика, карточкой персонажа, экипировкой и рецептами.
- Три типа оружия: меч (область перед героем), лук (узкий луч до 7 единиц), посох (узкий луч до 6 единиц, 3 маны). Трассеры декоративные; попадания рассчитываются мгновенно, это не физические снаряды.
- Броня: минус 4 входящего урона, минимум 1.
- Рывок: 0.22 с, перезарядка 3 с, неуязвимость на время рывка, проверка простых коллизий.
- Сила (+3 урона), жизненная сила (+10 HP), сосредоточение (+5 урона всплеском). Два стартовых очка, затем два за уровень.
- Травы, руда, тайники, монеты, поручение травницы, покупка зелий и продажа руды.
- Пять рецептов: клинок, лук, посох, доспех и зелье.
- Полосы HP врагов и отображение выбранного облика гостей в кооперативе.
- Сохранение v2 с импортом v1; новые данные хранятся отдельно, оригинальный слот v1 не перезаписывается.

## Управление

WASD — движение относительно экрана. ЛКМ — атака в сторону курсора. Q — всплеск (20 маны). E — взаимодействие. Пробел — рывок в направлении движения, а стоя — в сторону курсора. R — зелье. H — астральный хаб вне боя. I — вещи/экипировка. C — характеристики/облик. Esc — закрыть окно. Колесо — масштаб.

## Первый маршрут

Найдите три осколка у руин. Собирайте дерево, травы и руду. Травница стоит у колонны слева от начальной площадки: за 3 травы даёт 25 монет и 2 зелья. H открывает хаб. Верстак слева, склад справа. Создайте оружие и доспех, экипируйте через I. Вернитесь через портал; северная арка в лесу ведёт в Бездну.

## Состояние реализации

Это прототип. Нет PHP/MySQL, регистрации, полноценного дерева навыков, больших регионов и полной кампании. Пиксельные ракурсы статичны: ходьба имитируется покачиванием и отражением; нет настоящего directional animation atlas. Экипировка влияет на бой и интерфейс, но не меняет нарисованные слои тела героя. Облик не является классом: любую внешность можно сочетать с любым оружием.

Инвентарь — ограниченный каталог стеков материалов и переключатели созданной экипировки, а не универсальная drag-and-drop система с весом/лимитом стопок. Тайник одноразовый на локальный слот; добыча фиксированная, без генератора случайных предметов. Торговля — только зелье и руда.

Кооператив остаётся экспериментальным WebSocket relay до четырёх участников с расчётом врагов у хозяина. Здоровье игрока, ресурсы, торговля, квесты и сохранения локальны. Награды общих врагов получает хозяин; обмен, блокировки контейнеров и личная выдача наград гостям ещё не сделаны. Это не защищённый авторитетный сервер и не WebRTC/P2P.

## Сохранения

Ключ `forest-ash-v2` в localStorage, один слот на браузер/origin. При отсутствии v2 импортируется `forest-ash-v1`. Старый слот оставлен для отката. Новый пользователь получает два стартовых очка характеристик; при импорте старого персонажа — тоже два, без ретроспективного пересчёта уровней. Очистка данных сайта удалит прогресс. Сброс: `? → Начать заново`.

## Ассеты и права

PNG подготовлены из пользовательских изображений: 1.png, 2.png, 3.png и `2D RPG Character Asset Pack — 10 Unique Characters.jpg`. Автоматическая очистка фона может оставлять артефакты. Лицензия этих листов не приложена: перед публичным или коммерческим распространением подтвердите права. Нельзя считать присланные изображения автоматически свободными.

`public/assets/` содержит готовые файлы, дополнительных загрузок не требуется. Для повторной нарезки: Python + Pillow, `python scripts/extract_assets.py --input <папка-с-оригиналами>`. Основная игра не зависит от Python.

## Проверки

```
npm run build
node tests/rules.mjs
npx playwright install chromium
# Linux при необходимости: npx playwright install-deps chromium
# Сначала запустить сервер в другом терминале
TEST_URL=http://localhost:5173 node tests/v02.mjs
```

Для Windows задавайте TEST_URL через оболочку или используйте значение по умолчанию 5174 в tests/v02.mjs. Проверка покрывает выбор героя, распределение очков, рывок, инвентарь, крафт, экипировку и вход двух клиентов. Не заменяет полный сетевой/нагрузочный тест или проверку всего баланса.
