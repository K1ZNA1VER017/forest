# 0.3.0

- Удалены зависимости от нарезанных пользовательских листов; добавлены 4 оригинальные AI-иллюстрации и 194 runtime PNG с вариантами.
- Простые анимированные спрайты героя, вид сзади, оттенок броневого слоя.
- 4 региона, последовательное открытие печатей, 4 воспоминания, 4 поручения жителей.
- 5 фиксированных этажных планировок Бездны, сохранение убитых врагов текущей вылазки.
- 5 именованных хранителей с телеграфируемым круговым ударом, два сохраняемых финала/эпилога.
- Карта M, журнал J, дерево T из 6 навыков, активная защита F.
- Улучшения верстака/склада и закалка оружия в хабе.
- Общий серверный claim добычи, награды гостю за завершающий удар, раздельное сохранение мира/персонажа гостя.
- 4 оригинальных синтезированных музыкальных слоя с переключением по сцене/бою.
- Опциональный PHP API аккаунтов и одного слота, CSRF и ревизии; MySQL схема и инструкция.
- Браузерные, сетевые, формульные и PHP API тесты. Границы тестирования и невыполненные требования перечислены отдельно.

Это не полная большая RPG по всем пунктам ТЗ; см. SPEC-STATUS.md.
