# Обновление существующей игры до v0.3

Проверенная база: GitHub K1ZNA1VER017/forest, HEAD 35af58ed32de516463b1f424c202b499a2be3213 (v0.2). Эта сборка не отправлена в репозиторий автоматически.

1. Сделайте резервную копию текущей ветки/тег v0.2.
2. Распакуйте forest-ash-v0.3.zip. Загрузите **содержимое** папки forest-ash-v0.3 в корень репозитория, сохранив структуру. Не добавляйте node_modules, dist или .git. На сайте GitHub можно Add file → Upload files → Commit changes.
3. Версия package.json должна быть 0.3.0; должны появиться src/campaign.ts, src/account.ts, backend/, public/original/ и обновлённые public/assets/.
4. Старый scripts/extract_assets.py больше не нужен. В архиве его нет; при ручном наложении удалите его. Для чистого обновления через Git используйте приложенный binary-safe patch, который включает удаления.
5. В Render: дождитесь Auto Deploy или Manual Deploy → Deploy latest commit. Сборка и start-команда прежние. Активные комнаты при деплое закрываются, создайте их заново.
6. Откройте прежнюю ссылку. Новый слот v3 импортирует предыдущий. URL ассетов имеют версию ?v=3, чтобы заменить старые кэшированные изображения.

Для Git-патча из чистой рабочей копии указанного коммита:

```
git apply --index forest-v0.3.patch
git commit -m "Add original art and v0.3 campaign"
git push origin main
```

Не применяйте патч поверх уже скопированного архива. Если ветка ушла вперёд, сначала сравните изменения.

## Аккаунты

Текущий Render Node.js сервис продолжит работать с локальными сохранениями. Добавленный PHP API **не заработает сам** после загрузки файлов: необходимы PHP+MySQL, общий origin/reverse proxy и VITE_API_BASE. См. backend/README.md. Не публикуйте реальные DB-пароли и не размещайте их в VITE_*.

## Первые проверки

M — четыре региона; T — навыки; B в приюте — улучшения. Победите хранителей, пройдите пять этажей и проверьте оба финала. Полный список невыполненных требований — SPEC-STATUS.md.
