# Сверка с большим ТЗ · v0.3

**Короткая кампания имеет начало и два финала. Полная игра по ТЗ не завершена.** Ниже — фактические границы, а не обещание готовности большого релиза.

| Раздел ТЗ | Статус v0.3 |
| --- | --- |
| Браузер, изометрия, WASD, мышь, приближение | Реализовано, проверено в Chromium |
| 2D-пиксельные персонажи в 3D-мире | Реализовано на собственных ассетах; анимации простые |
| 4+ больших региона, 10+ отдельных интерьеров | 4 небольшие наружные карты; 10 интерьеров нет |
| 25+ уникальных модулей Бездны | 5 планировок по 5 экземпляров общего модуля; не 25 уникальных комнат |
| 15+ врагов с разным поведением | 6 графических семейств существ; базовый общий AI |
| 5 боссов | 5 именованных хранителей, общий шаблон телеграфа/контакта; нужны уникальные паттерны |
| 12+ NPC | 4 диалоговых жителя с поручениями; не 12 |
| 40+ игровых предметов | 45 оригинальных иконок доступны, реально используемых предметных типов значительно меньше 40 |
| Амнезия без штрафов к характеристикам | Реализовано через 4 воспоминания |
| Астральный хаб без NPC, возврат с применением вне боя | Реализовано |
| Улучшения верстаков/склада | 3 уровня; склад пока только древесины |
| HP/мана, бой, навыки с перезарядкой, нет выносливости | Реализовано |
| Характеристики и отдельные очки дерева | 3 характеристики, 6 узлов с условиями, включая F |
| Сочетания экипировки определяют навыки | Меч/лук/посох меняют атаку; активные умения от разных предметов не реализованы полностью |
| Видимые слои экипировки | Упрощённый вариант брони; отдельные оружейные/броневые анимационные слои ещё нужны |
| Универсальные ячеечные инвентарь/склад, стаки | Фиксированные стеки + переключатели экипировки; общего контейнерного движка нет |
| Крафт и рецепты по уровню верстака | 5 рецептов, открытие части на уровне 2, закалка на 3 |
| Материалы разных миров | Базовые материалы; уникальные полные цепочки Бездны/NPC не готовы |
| Два финала | Реализованы с разными эпилогами и флагом сохранения |
| До 4 игроков, код, хаб, поднятие | Реализовано как экспериментальный WebSocket relay |
| Best-effort WebRTC/P2P | Нет: архитектурное отклонение, пока серверный relay |
| Мир хозяина отдельно от персонажа гостя | Реализовано для локальных слотов, проверено двумя браузерами |
| Эксклюзивный обыск тела/контейнера | Атомарный claim общего предмета; поиска с длительностью и тел нет |
| Обмен предметами между игроками | Не реализован; торговля только с NPC |
| Автосохранение одного персонажа на аккаунт | Локальный слот работает; PHP API и адаптер готовы, облако требует развёртывания |
| Email+пароль, PHP+MySQL/OpenServer | API/SQL/инструкция включены. PHP интеграционные тесты — SQLite; MySQL и публичное размещение не проверены |
| Музыка/эффекты/диалоги без озвучки | 4 оригинальных синтезированных лупа, базовые синтезированные SFX, текстовые диалоги |
| Бесплатный публичный запуск | Render-конфигурация есть; эта сборка не загружена в пользовательский GitHub/Render |
| Релизное качество/баланс/защита | Не достигнуто: нужны живые прохождения, нагрузочные тесты, серверная валидация и аудит |

Следующий реальный релизный этап: непрерывное прохождение/баланс, серверные аккаунты на целевой инфраструктуре, полноценные контейнеры/обмен, уникальные боевые паттерны, расширение контента и анимаций. Эти пункты нельзя честно отметить выполненными на основании только генерации файлов.
