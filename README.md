# Лесной пепел · основа игры v0.1

Рабочий браузерный прототип по `iso_fantasy_rpg_plan.md`. Это первый технический срез, **не полная реализация ТЗ**. В этой поставке нет исходных утверждённых ассетов: вся геометрия, пиксельные спрайты и короткие синтезированные звуки временные.

## Запуск на Windows / локально

1. Установите Node.js 22 LTS (или 20.19+) с npm.
2. Откройте терминал в каталоге проекта.
3. Выполните `npm ci`.
4. Выполните `npm run dev`.
5. Откройте `http://localhost:5173`.

`npm run build` проверяет TypeScript и собирает статический клиент в `dist/`. Сетевые комнаты требуют отдельно запущенного `server.mjs`; один статический хостинг их не обслужит. Текущий сервер использует Vite middleware и предназначен для разработки, а не публичного production-размещения.

OpenServer пока не нужен: PHP и база данных **ещё не подключены**. Их добавление — следующий отдельный этап. Не размещайте этот прототип как защищённую публичную RPG: проверка боевых событий ограничена, аккаунтов и античита нет.

## Что работает

- Трёхмерное стилизованное окружение на Three.js и пиксельные billboard-персонажи.
- Ортографическая камера, движение относительно экрана, масштабирование, простые коллизии.
- Текстовое вступление и задача найти три осколка памяти.
- Лес с руинами, астральный хаб со складом и верстаком, тестовый зал Бездны.
- Удар в сторону курсора, круговой всплеск, мана и перезарядка, зелья.
- Один тип обычного врага и его усиленный вариант — страж.
- Опыт и уровни; смерть сохраняет вещи и сбрасывает текущий опыт.
- Сбор дерева и осколков, крафт клинка и зелий, склад древесины.
- Возврат в хаб с применением 2 секунды, прерыванием движением/атакой/получением урона и запретом в бою.
- HUD, мини-карта, подсказки, простые звуковые сигналы (включаются кнопкой).
- Автосохранение в localStorage раз в 5 секунд и после важных действий.

## Управление

| Действие | Клавиша |
| --- | --- |
| Движение | WASD |
| Удар в сторону курсора | ЛКМ |
| Круговой всплеск, 20 маны | Q |
| Взаимодействие / сбор / поднять союзника | E |
| Зелье | R |
| Применить путь в хаб / вернуться | H |
| Инвентарь | I |
| Масштаб | Колесо мыши |
| Закрыть окно | Esc |

Первый маршрут: найдите светящиеся осколки возле руин, соберите древесину → нажмите H → подойдите к верстаку и нажмите E → создайте клинок → вернитесь через портал → войдите в арку на севере леса, ведущую в Бездну.

## Сетевой тест

Откройте «Пригласить в мир», создайте комнату. Другу передайте **адрес той же работающей игры** и код из 6 символов. Нужен доступ к серверу по сети: локальный `localhost` на вашем ПК другу недоступен. Для интернета требуется публичное размещение с HTTPS/WSS или туннель.

Реализован **WebSocket relay, не согласованный в ТЗ WebRTC/P2P**. Это промежуточный транспорт для ранней проверки. В комнате максимум 4 участника; хозяин рассчитывает движение/здоровье врагов, клиенты передают позиции и удары. Хозяин выбирает общую локацию. При отключении хозяина комната закрывается. Есть базовое поднятие павшего союзника.

Ограничения сетевого среза:
- Проверено подключение двух браузерных клиентов; длительная нагрузка четырьмя клиентами и реальные сети с задержками пока не проверялись.
- Сбор предметов, квест и склад локальны. Нет общей блокировки контейнеров, обмена предметами и сохранения мира хозяина на сервере.
- Награды за общих врагов пока начисляются хозяину; личная выдача добычи гостям — следующий этап.
- Здоровье героя рассчитывается локально; это не защищённая серверная симуляция.
- Повторный вход в локацию пересоздаёт врагов. Уже собранные ресурсы сохраняются локально.
- Нет восстановления сессии при разрыве соединения и передачи роли хозяина.

## Сохранение

Один слот **на браузер и origin**, а не на аккаунт. Ключ: `forest-ash-v1`. Зачистка данных сайта удалит прогресс. Для сброса используйте `? → Начать заново`. Нет синхронизации между устройствами.

## Структура

- `src/main.ts` — игровой цикл, процедурные сцены, прототип RPG-систем, сетевой клиент.
- `src/style.css` — HUD, вступление и диалоги.
- `index.html` — интерфейс на русском.
- `server.mjs` — сервер разработки и комнаты WebSocket.
- `tests/smoke.mjs` — браузерная smoke-проверка.
- `ROADMAP.md` — ближайшие работы и границы реализации.

Для раннего среза клиент намеренно собран в одном модуле; перед расширением контента его нужно разделить на renderer/world/combat/inventory/network/persistence. Геометрию и спрайты можно заменить в фабриках `tree`, `ruin`, `sprite`, `addProp`, `enemy`.

```
node tests/smoke.mjs
```

Smoke-тест в Chromium прошёл: загрузка WebGL-сцены без JS-ошибок, ввод движения, перезарядка умения, окно инвентаря, применение пути в хаб, создание комнаты, вход второго клиента, закрытие сессии при выходе хозяина. Это не полное тестирование боевого баланса и прохождения.
