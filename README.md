# Лесной пепел · v0.3 · короткая кампания

Рабочая изометрическая RPG-сборка с собственными ассетами и коротким сюжетным маршрутом до двух финалов. **Это завершённый по структуре небольшой срез, а не весь большой объём исходного ТЗ.** Подробная сверка — SPEC-STATUS.md.

Основана на v0.2 вашего репозитория `K1ZNA1VER017/forest`. Последний проверенный публичный коммит: `35af58ed32de516463b1f424c202b499a2be3213`. Изменения не отправлялись в GitHub или Render из этой среды.

## Запуск

Node.js 22 LTS рекомендуется, 20.19+ поддерживается.

```
npm ci
npm run dev
```

Откройте http://localhost:5173. `npm run build` проверяет TypeScript и собирает dist. Production: NODE_ENV=production + npm start. На Render эти настройки находятся в render.yaml; на Windows переменную окружения задавайте средствами вашей оболочки.

## Короткая кампания

1. Проснитесь в Сером лесу, выберите облик, соберите припасы и осколки.
2. Победите Тернового пастыря у руин. Первая печать откроет Тихую топь на карте M.
3. Пройдите Тихую топь, Пепельный карьер и Белый перевал. Каждый хранитель возвращает воспоминание и открывает следующий регион.
4. Улучшайте верстак в приюте (B), создавайте оружие и броню, распределяйте характеристики (C) и навыки (T). Выполняйте поручения четырёх жителей для припасов и очков.
5. Соберите четыре печати. Вход в Бездну — древняя арка или карта M.
6. Очистите пять этажей; ключ-переход работает только после гибели всех врагов этажа. На пятом этаже победите стража и коснитесь печати.
7. Удержите печать либо освободите узника. Оба выбора имеют собственный эпилог и сохраняются. Исследование можно продолжить после финала.

Это не обещание 10–20 минут или полного баланса. Время и сложность ещё требуют пользовательского тестирования. Карту можно открывать в любом регионе, переходы вне боя; в кооперативе мир переключает хозяин.

## Собственные ассеты

В public/assets — **194 runtime PNG**, включая цветовые/анимационные варианты; это не 194 разных предмета. Ранее вырезанные изображения пользователя заменены, их пиксели не используются.

- Четыре новые AI-иллюстрации: странница, её вид сзади, провидица, каменный страж — public/original.
- Пять обликов героя — цветовые варианты одного оригинального персонажа, не пять отдельно нарисованных героев.
- Простые четырёхкадровые варианты движения/вида сзади/брони. Это программное смещение ног и цветовые слои, не профессиональная покадровая анимация боя.
- Собственные небольшие спрайты существ, 45 иконок предметной тематики, сердца интерфейса.
- Четыре собственных синтезированных 24-секундных музыкальных слоя (лес, хаб, Бездна, бой) и синтезированные сигналы действий. Звук включается кнопкой.
- Галерея: ORIGINAL-ASSETS.html (автономный HTML). Исходники генераторов: scripts/original_assets.py и scripts/make_audio.py. Для них нужен Python+Pillow; игре Python не нужен.

Не заявляется исключительность авторских прав на AI-вывод или юридическая экспертиза. В пользовательских изображениях использовалось только общее направление фэнтези-пиксельной графики, не нарезки или трассировка.

## RPG и мир

Три типа оружия, броня, пять рецептов, три характеристики и отдельные очки навыков. Шесть узлов навыков включают активный Покров, регенерацию маны, усиление всплеска, рывок и лечение за убийство. Верстак и склад улучшаются до 3; верстак 2 открывает посох/броню, 3 — закалку до +3. Нажмите B в хабе. Экипированный доспех меняет оттенок слоя тела; тип оружия пока не меняет отдельный нарисованный слой в руках.

Четыре наружные карты отличаются палитрой, пропами и врагами; это небольшие арены исследования, не огромные регионы. Пять именованных хранителей используют общий каркас боя и телеграф круговой атаки. Обычные существа используют базовое преследование/контактный урон, а не 15 разных боевых AI.

В Бездне пять фиксированных соединённых планировок, каждая из пяти экземпляров общего комнатного модуля. Это не 25 уникальных вручную оформленных модулей и не случайный генератор. Хранители регионов не возрождаются. Обычные враги регионов возвращаются при входе, позволяя добывать материалы. Убитые враги текущей вылазки Бездны запоминаются по этажу. Выбор «новая вылазка» сбрасывает их, но не личную добычу. Частично повреждённые выжившие враги после перезагрузки восстанавливают здоровье.

Инвентарь — фиксированные стеки материалов и переключатели созданных предметов, без общего drag-and-drop. На складе хранится древесина с ограниченной вместимостью; универсального многоячеечного склада всех предметов ещё нет.

## Кооператив

WebSocket relay, максимум четыре подключения. Хозяин ведёт врагов, переходы, печати и финал; при его выходе комната закрывается. При входе участники собираются в хабе. Скопируйте публичный адрес игры и код комнаты.

- Подбор общей добычи обрабатывается через серверный атомарный claim: предмет получает первый запросивший, для остальных он исчезает.
- Опыт/обычные награды получает игрок, нанёсший завершающий удар. Отдельные награды за открытие печати относятся к миру хозяина.
- Гость видит печати/верстак хозяина, расходует свои материалы и сохраняет личные характеристики отдельно от собственного мира. После выхода собственный мир восстанавливается.
- Есть базовое поднятие союзника. Нет UI торговли между игроками, поиска тела с длительностью и полноценного эксклюзивного обыска контейнера.

Сервер доверяет расчётам хозяина и части клиентских данных; это не античит и не защищённая игровая экономика. Нет восстановления сессии/смены хозяина. Если хозяин погиб, его игровой цикл врагов приостанавливается до возрождения/поднятия. Проверялись четыре сетевых подключения и два браузерных клиента, не четыре клиента под реальной интернет-нагрузкой.

## Сохранения и аккаунты

По умолчанию один слот localStorage `forest-ash-v3` на браузер/origin. Импорт v2/v1 при отсутствии v3; старые слоты не перезаписываются. При смерти вещи и уровень остаются, текущий опыт обнуляется. Сброс — ? → Начать заново.

Включён отдельный PHP 8.2 API и схема MySQL: backend/. Регистрация email/пароль, сессионная авторизация, CSRF, один слот на пользователя, проверка владельца и ревизии. Для подключения задайте VITE_API_BASE при сборке и разверните PHP+MySQL на доступном сервере **с одного origin**. Инструкция backend/README.md.

**Текущий Node.js Render не содержит автоматически PHP и MySQL.** Без настройки кнопка «Аккаунт» честно показывает локальный режим. API тестировался с PDO SQLite как тестовой БД, а не на реальной MySQL-инсталляции. Нет подтверждения email, восстановления пароля и production-защиты от перебора через новые сессии. После входа облачный автосейв включается явным выбором загрузки/сохранения и работает каждые 30 секунд в текущем сеансе.

## Проверки

```
npm run build
npm run test:rules
npm run test:api                 # требуется PHP CLI + pdo_sqlite
npx playwright install chromium
# Linux: npx playwright install-deps chromium
# При запущенной игре; TEST_URL задайте средствами вашей оболочки
TEST_URL=http://localhost:5173 npm run test:campaign
TEST_URL=http://localhost:5173 npm run test:network
TEST_URL=http://localhost:5173 node tests/guest-world.mjs
```

Браузерные тесты используют подготовленные сохранения для проверки отдельных этапов. Они **не являются непрерывным прохождением обычным персонажем с первого шага до финала**. Боевой баланс, длительные сессии и совместимость разных устройств ещё требуют проверки.
